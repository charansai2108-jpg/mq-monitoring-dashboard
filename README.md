# MQ Monitoring Dashboard

A monitoring dashboard built using Python and Streamlit to track IBM MQ queue and channel health.

## Features

* Queue depth monitoring
* Queue health classification (Healthy, Warning, Critical)
* Channel status monitoring
* Alert generation
* Queue Summary Dashboard
* Channel Summary Dashboard
* Queue Details Table
* Channel Details Table
* Queue Depth Visualization
* Report Download
* Last Updated Timestamp

## Technologies Used

* Python
* Streamlit
* Pandas
* Plotly
* CSV

## Sample Monitored Queues

* PAYMENT.IN
* NEFT.IN
